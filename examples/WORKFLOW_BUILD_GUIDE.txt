MINIMAX H3 IMAGE WORKFLOW V12
=============================

This is an experimental, entirely AI-coded project. Review and test every
workflow on your own setup. Bug reports, corrections, and pull requests are
welcome on GitHub.

MODEL FAMILY
============

Text to Image and Image to Image use the FL2VA checkpoint.
Reference Edit uses the separate REF2VA checkpoint.

All workflows use:
- Qwen3-VL MiniMax text encoder loaded with CLIPLoader type=minimax
- minimax_h3_video_vae_fp16.safetensors
- BasicGuider; H3 is CFG-distilled and does not need a negative CFG branch
- SamplerCustomAdvanced
- MiniMax H3 Image - Exact Frame Decode
- MiniMax H3 Image - Single Image Output

FRAME PROFILES
==============

- recommended | 5 frames: best speed/quality balance and the default.
- maximum quality | 20 frames (slow): more temporal context, potentially higher
  quality, and a much longer generation time.

Both profiles return one image only. T2I, REF2VA, and five-frame I2I use frame 0.
Twenty-frame FL2VA I2I uses frame 3 because frames 0-2 remain close to the source
anchor. H3 processes the whole temporal packet jointly, so it cannot stop early.

TEXT TO IMAGE
=============

Use MiniMax H3 Image - Text to Image with FL2VA.
Connect Resolution Preset width/height to the image node.

Recommended setup:
- 5 frames + quality / 20 steps for the standard quality preset.
- 5 frames + speed / 12 steps for faster generation.
- 20 frames + quality / 20 steps for maximum quality when time is secondary.

Use stable_quality or best_quality in Single Image Output. Keep
emit_candidate_batch disabled unless inspecting candidate frames.

IMAGE TO IMAGE
==============

Use MiniMax H3 Image - Image to Image with FL2VA.
Connect LoadImage to:
- Resolution Preset.source_image when using the source aspect ratio
- Image to Image.source_image

The source becomes a first-frame latent anchor. Source Fidelity changes the
preservation language added to the prompt; it is not a denoise-strength control.
With 20 frames, Exact Frame Decode automatically skips the source-like transition
and returns decoded frame 3. The five-frame profile continues to return frame 0.
Connect Image to Image.fitted_source to Single Image Output.source_image and use
balanced_edit to rank both edit quality and source similarity.

REFERENCE EDIT
==============

Use MiniMax H3 Image - Reference Edit with REF2VA.
Connect LoadImage to Resolution Preset and Reference Edit as above.
Use quality / 20 steps as the starting sampling profile.

Reference Edit regenerates from visual reference features rather than using the
source as an exact first-frame anchor. It is useful for semantic changes such as
clothing, material, style, or environment. Increase Source Fidelity when identity
or composition drifts; reduce it when H3 refuses the requested change.

RESOLUTION
==========

- balanced / 0.70 MP: faster draft
- native detail / 0.98 MP: native-area final
- 2, 4, 8 MP and custom 0.1-64 MP: unlocked experiments

High resolution sharply increases VRAM, RAM, decode time, and pagefile pressure.
It often adds canvas pixels without proportional learned detail. Enable
limit_to_native_area for the conservative approximately 1 MP cap.
